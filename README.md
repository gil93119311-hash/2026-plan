# 말로 가계부 (Voice Expense Diary)

말로 기록하는 가계부 웹앱(PWA). 앱 파일은 `docs/` 폴더에 있습니다.

- 🎤 말하면 날짜·시간·카드·분류를 자동으로 정리: “어제 점심 신한카드로 김치찌개 9천원”
- 📔 달력 + 다이어리 화면
- 📊 결산: 일간·주간·월간·분기·6개월·1년, 분류별·카드별, 이전 기간과 비교
- ⏰ 고정지출(카드결제일·대출이자·월세 등)과 지출할 것 알림, 캘린더(.ics) 내보내기
- 💾 기록은 휴대폰 안에만 저장, 백업/복원·CSV 내보내기

## 휴대폰에 설치
1. GitHub 저장소 Settings → Pages → Branch를 이 브랜치, 폴더 `/docs`로 지정
2. 휴대폰에서 주소 `https://<아이디>.github.io/2026-plan/` 열기
3. 안드로이드(Chrome): 메뉴 ⋮ → “홈 화면에 추가” / 아이폰(Safari): 공유 → “홈 화면에 추가”

테스트: `node tests/parser.test.js`
